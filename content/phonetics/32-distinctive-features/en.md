# Distinctive features and natural classes

## Why break sounds down?

The phoneme `/p/` is not an indivisible "atom". It is a **bundle** of features: voiceless, bilabial, plosive... Breaking it down lets us **group** sounds that behave alike and write **rules** compactly.

## Distinctive features

A **distinctive feature** is the smallest property that **distinguishes** one sound from another in a language. **Roman Jakobson** (1941) proposed the theory of features; **Chomsky and Halle** (1968, *The Sound Pattern of English*) formalised them as **binary** features (+ or −).

A few commonly used features:

| Feature | Meaning |
|---|---|
| **[±voice]** | vocal folds vibrate |
| **[±nasal]** | air through the nose |
| **[±continuant]** | continuous airflow (fricatives, approximants: +; stops: −) |
| **[±sonorant]** | high sonority (vowels, nasals, approximants: +) |
| **[±coronal]** | tongue tip or blade raised |
| **[±anterior]** | articulation in front of the postalveolar region |
| **[±high], [±back]** | height and backness of the tongue body |
| **[±round]** | rounded lips |

Other approaches use **privative** features (present or absent only), and the list of features differs between theories.

## Example: some English consonants

| Sound | voice | continuant | nasal | coronal |
|---|---|---|---|---|
| `p` | − | − | − | − |
| `b` | + | − | − | − |
| `t` | − | − | − | + |
| `d` | + | − | − | + |
| `k` | − | − | − | − |
| `ɡ` | + | − | − | − |
| `s` | − | + | − | + |
| `z` | + | + | − | + |
| `m` | + | − | + | − |
| `n` | + | − | + | + |

(For `p k` and `b ɡ` you need place features such as [labial], [dorsal] to tell them apart.)

## Natural classes

A **natural class** is a group of sounds that can be specified by **fewer features** than each sound alone: for example {`p t k`} = [−voice, −continuant, −nasal]. Natural classes are the targets of phonological **rules** because sounds sharing features are usually **affected together**.

## Example: the English plural

The suffix -s has three forms: `/s/` (*cats*), `/z/` (*bags*), `/ɪz/` (*boxes*). One can assume the underlying phoneme is **`/z/`** and two rules:

1. **Vowel insertion**: insert `/ɪ/` between `/z/` and a **sibilant** ([+sibilant]: `s z ʃ ʒ tʃ dʒ`).
2. **Voicing assimilation**: `/z/` becomes `[s]` after a **[−voice]** sound.

Both rules use **natural classes** ([+sibilant], [−voice]) rather than listing each sound. This is the power of features.

## Features and phonetics

Features have an **articulatory** basis ([voice] is vocal fold vibration) and an **acoustic** basis (for example [±continuant], [±sonorant]). Stevens' **quantal theory** (1989) proposes that features are common because they lie in regions of articulation where **small articulatory changes cause only small acoustic changes**. That is where phonetics and phonology meet.
