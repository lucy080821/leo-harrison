# Backgrounds, borders, radius and shadows

## Backgrounds

```css
.box {
  background-color: #eaf2fb;                       /* background color */
  background-image: url("photo.jpg");              /* background image */
  background-size: cover;                          /* fill (cropping if needed) */
  background-position: center;                     /* centered */
  background-repeat: no-repeat;                    /* no tiling */
}
```

Shorthand: `background: #eaf2fb url("photo.jpg") center / cover no-repeat;`

| `background-size` | Meaning |
|---|---|
| `cover` | Fills the box, may be cropped |
| `contain` | Shows the whole image, may leave gaps |

## Gradients

A gradient is an **image** generated by CSS, no image file needed.

```css
background: linear-gradient(135deg, #0b6fd6, #0aa5b8);        /* at 135° */
background: linear-gradient(to right, #fff, #0b6fd6 60%, #000); /* several stops */
background: radial-gradient(circle, #fff, #0b6fd6);            /* radiating circle */
```

## Borders and rounding

```css
border: 2px solid #0b6fd6;
border-bottom: 1px dashed #999;
border-radius: 12px;         /* round all 4 corners */
border-radius: 50%;          /* a circle (if width = height) */
outline: 2px solid orange;   /* an outer line that takes no space */
```

## Shadows

```css
box-shadow: 0 8px 24px rgba(0, 0, 0, 0.25);
/*          x  y   blur  color */
box-shadow: inset 0 0 0 2px #0b6fd6;  /* inner shadow (border effect) */
text-shadow: 1px 1px 2px rgba(0,0,0,.4);
```

The four values are: horizontal offset, vertical offset, blur and color. Use `rgba()` for a translucent shadow, which looks more natural than solid black.

## Images inside a frame

When forcing an image into a box of a different ratio, use `object-fit` so it isn't distorted:

```css
img { width: 100px; height: 100px; object-fit: cover; border-radius: 50%; }
```

## Transparency

```css
opacity: 0.6;                  /* fades the WHOLE element and its content */
background: rgb(0 0 0 / 0.6);  /* only the background is translucent, text stays crisp */
```
