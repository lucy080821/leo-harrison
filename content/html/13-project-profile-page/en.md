# Project: a personal profile page

This is a **capstone** lesson: you'll build a complete personal page with HTML alone. Look at the sample page in the file on the right, then do the two exercises yourself.

## What will you use?

- **Document skeleton** (`<!DOCTYPE>`, `<html lang>`, `<head>` with `title`, `meta viewport`).
- **Semantic layout:** `header`, `nav`, `main`, `section`, `footer`.
- **Anchor links:** `<a href="#about">` scrolls to the element with `id="about"`.
- **Lists, emphasised text, images** with `alt`.
- **A contact form** with `label`, `required` and a `submit` button.

![Wireframe of the profile page](/lessons/html/13-project-profile-page-fig-en.svg)
*Wireframe of the profile page*

## Suggested workflow

1. **Sketch the structure** on paper: which parts the page has and in what order.
2. Write the **frame** (header, main, footer) first, with no real content yet.
3. Add each `<section>` with a clear `id`, then connect the `nav` menu to them.
4. Fill in content, add images with `alt`, add the form.
5. Test: click every link, try submitting the form to see the browser's `required` error.

## Self-check

- [ ] Only **one** `<h1>`, and no skipped heading levels?
- [ ] Every image has sensible `alt`?
- [ ] Every input has a `label`?
- [ ] Every `#...` link points to a real `id`?
- [ ] Tab through the page: is everything reachable by keyboard?

The next course (CSS) will make this page look good. Keep your work to build on it!
